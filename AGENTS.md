
## BeHeard editorial and design preferences

- Use the wording in the approved project brief for public website text. Ask Nyasha before adding new wording, claims, quotations or features outside the brief.
- Keep the voice of the people behind BeHeard. Preserve attribution and use quotation marks only for verified direct quotations.
- Use authentic, approved photographs with appropriate consent. When an image is unavailable, design the section around its text. Omit placeholder artwork, mock portraits and temporary logos.
- Prefer a calm palette, readable type and navigation organised around what visitors need. Check visual changes in the actual browser, including while scrolling when relevant. Use the user's screenshot as the reference when correcting a visual issue.
